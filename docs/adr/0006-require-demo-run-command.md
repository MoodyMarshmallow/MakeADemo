# Require a Prepared Demo Command

MakeADemo requires Repo Preparation to produce a prepared demo command and local URL that start the app in a deterministic demo mode without secrets, external databases, OAuth, paid services, or manual setup. The Preparation Manifest is the source of truth for this command and URL; a repo-provided `makeademo.config.json` may be useful evidence, but it is no longer the primary contract. During development, both Daytona sandboxes are created with `networkBlockAll: false`, so dependency installation, build, runtime, Capture Path Validation, and Footage Capture retain network access. Daytona sandbox-firewall Runtime Network Lockdown is explicitly deferred and is not a hard-failure gate in this stage of the product. Browser-level external requests remain intercepted and reported where supported, and those observed requests can still fail validation or capture.
